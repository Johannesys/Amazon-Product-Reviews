Dashboard interaktif untuk menganalisis sentimen ulasan produk Amazon menggunakan Python dan NLP.

## Fitur
- Analisis sentimen otomatis (Positif/Netral/Negatif)
- Visualisasi distribusi sentimen
- Tren sentimen per bulan (Time Series)
- Prediksi sentimen real-time

## Tools & Library
- Python, Pandas, NumPy
- TextBlob (NLP)
- Matplotlib, Seaborn
- Streamlit (Dashboard)

## Cara Menjalankan
1. Install library: `pip install pandas numpy matplotlib seaborn scikit-learn textblob streamlit`
2. Jalankan dashboard: `streamlit run app.py`
